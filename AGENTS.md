# Trabalho no projeto

Use os agentes nomeados em `.codex/agents/` para suas responsabilidades. O principal coordena escritores exclusivos e integra resultados.

Nesta validação, toda escrita e toda aplicação de teste devem usar exclusivamente `mongodb://127.0.0.1:27017/salgados_financeiro_test`. Não apagar bancos, coleções ou registros nem reinicializar dados. Use identificadores exclusivos por execução e preserve dados anteriores.

Não escrever em `salgados_mvp`, inclusive por seeds de inicialização, sem explicar as gravações e obter confirmação explícita. Não iniciar a API com configuração operacional durante QA.

Registre comandos, resultados, contagens e limitações. Não confunda agentes configurados com processos ativos, nem implementação com validação concluída. Não sobrescreva trabalho de outro agente.
